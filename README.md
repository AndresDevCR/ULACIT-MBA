# ULACIT MBA - Análisis de la tesis

Repositorio complementario de la tesis MBA sobre transformación digital en el sector financiero costarricense.

## Contenido

- `Analisis_Tesis.ipynb`: cuaderno Jupyter con el pipeline reproducible de análisis cuantitativo.
- `encuesta_template.csv`: plantilla de estructura esperada para la encuesta.
- `encuesta_respuestas.csv`: archivo de respuestas utilizado para el análisis.
- `tabla_*.csv`: tablas exportadas desde el pipeline para integrar en la tesis.
- `requirements.txt`: dependencias necesarias para ejecutar el notebook.

## Cómo ejecutar

1. Instalar dependencias:
   ```bash
   pip install -r requirements.txt
   ```
2. Abrir `Analisis_Tesis.ipynb` en Jupyter o VS Code.
3. Verificar que `encuesta_respuestas.csv` esté en la misma carpeta.
4. Ejecutar todas las celdas.

## Publicación

El contenido de este repositorio acompaña la tesis y documenta el análisis cuantitativo reproducible en Python.
